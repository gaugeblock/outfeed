# GB-77: Enhance Outfeed Release with Progress Reporting, --no-llm Flag, and Resilient Error Handling

## Objective
Provide real-time progress visibility during `outfeed release` and `outfeed release --all`, add a `--no-llm` / `--deterministic` flag across release commands for instant offline operation, and handle remote LLM synthesis timeouts and errors gracefully without hanging or spamming raw router traces.

## Problem Statement
When running `outfeed release --all`:
1. It silently evaluated repos until reaching `benchwork`, where Sawhorse attempted to call a failing remote LLM endpoint (`api.cline.bot` returned 500).
2. The user was left with no indication of which repository was being operated on or what phase was executing.
3. The process took over 20 seconds of retries and logged raw router `WARN` traces without application context.
4. There was no CLI flag to disable LLM synthesis and generate deterministic changelogs offline.

## Architecture & Invariants
1. **Progress Observability:**
   - `release_repo` and `release_all` accept `&dyn ProgressReporter`.
   - Each repository emits start, update (planning, synthesizing, committing, installing, pushing), and completion status (`Skipped` for clean checkouts, `Success` for released versions).
2. **Deterministic / Offline Execution:**
   - `ReleaseOpts`, `PlanOpts` include `no_llm: bool`.
   - `--no-llm` (alias `--deterministic`) flag available on `outfeed plan`, `outfeed apply`, and `outfeed release`.
   - When enabled, changelog generation directly invokes `format_release_section` without loading or querying Sawhorse.
3. **Resilient Synthesis Fallback:**
   - Wrap `call_sawhorse` in a 10-second timeout.
   - Catch errors and log a clean informative message before immediately returning the deterministic changelog.
4. **Code Quality Invariants:**
   - Hard 250 LOC file limit across all Rust source files.
   - Tier 2 clippy and unit test verification.

## Execution Steps
1. Update `outfeed-core::model` and `engine` to accept `no_llm: bool`.
2. Update `outfeed-core::synthesis` with 10s timeout and graceful fallback.
3. Update `outfeed-core::release` with `ProgressReporter` integration.
4. Update `outfeed-cli` args and command handlers (`plan`, `apply`, `release`) to wire `--no-llm` / `--deterministic` and progress reporting.
5. Add unit and integration tests verifying progress reporting and `--no-llm` behavior.
6. Tier 2 verification, install binary to `~/.cargo/bin`, dogfood, and commit.
