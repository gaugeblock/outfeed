# GB-72: Add --all Suite-Wide Orchestration Flag to outfeed release

> **Status:** InProgress  
> **Parent Epic:** Release Delivery Infrastructure  
> **Target Scope:** `outfeed-core`, `outfeed-cli`  
> **Key Invariants:**  
> 1. Hard 250 LOC rule on all `.rs` files.  
> 2. Zero-panic error handling with strongly typed errors via `thiserror`.  
> 3. Clean fallback when individual repo is omitted (`default_value = "."`).  
> 4. Deterministic topological iteration order across the 10 suite tools.  

---

## 1. Overview & Objectives

`outfeed release` orchestrates the complete SemVer release pipeline (`plan` -> `apply` -> `install` -> `push` -> `publish`). While other subcommands (`install --all`, `status --all`, `push --all`) support suite-wide execution across all 10 repositories, `outfeed release` required a specific `<REPO>` argument and lacked an `--all` option.

`GB-72` adds:
1. `outfeed release --all`: Iterates through all 10 suite repositories (`SUITE_TOOLS`) in dependency order.
2. For each repository with unreleased commits, executes the full release pipeline; clean repositories are skipped.
3. Respects all flags (`--dry-run`, `--skip-install`, `--skip-push`, `--skip-publish`, `--json`).
4. Makes `<REPO>` optional (`default_value = "."`), allowing `outfeed release` within a repository directory or `outfeed release <REPO>` from root.

---

## 2. Implementation Steps

1. In `outfeed-core`:
   * Add `release_all(workspace_root: &Path, opts: &ReleaseOpts) -> Result<Vec<ReleaseSummary>, OutfeedError>` in `crates/outfeed-core/src/release.rs`.
   * Export `release_all` in `crates/outfeed-core/src/lib.rs`.
2. In `outfeed-cli`:
   * Update `ReleaseArgs` in `crates/outfeed-cli/src/args/release.rs` to add `#[arg(long)] pub all: bool` and make `repo` default to `"."`.
   * Update `handle_release` in `crates/outfeed-cli/src/commands/release.rs` to handle `args.all`.
   * Add unit/CLI test in `crates/outfeed-cli/tests/` or `crates/outfeed-core/tests/`.
3. Verification:
   * Tier 2 checks: `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test --workspace` in `outfeed`.
   * Test `outfeed release --all --dry-run` dogfooding.
