# GB-74: Implement outfeed clone and bootstrap commands for suite-wide and selective repo setup

> **Status:** Ready  
> **Target Scope:** `outfeed-core`, `outfeed-cli`  
> **Key Invariants:**  
> 1. Hard 250 LOC rule on all `.rs` files.  
> 2. Zero-panic error handling with strongly typed errors via `thiserror`.  
> 3. Standalone independence: does not require submodules or complex gitdir pointers.  
> 4. Idempotent execution: existing repositories are detected, inspected, and skipped cleanly.  

---

## 1. Overview & Objectives

As the `gaugeblock` meta-harness evolves into the primary developer and contributor entrypoint (`gaugeblock/gaugeblock`), developers and agents need a first-class, reliable mechanism to clone and initialize member repositories.

Following the design directive to eliminate ad-hoc shell scripts and consolidate developer workflow under `outfeed`:
1. `outfeed clone` clones all 10 suite repositories (`--all`) or a specific subset of named tools (`outfeed clone miter storypole`).
2. Supports `--locked` to read `suite.lock` and checkout the pinned git tag or commit SHA for each cloned tool.
3. Supports protocol selection via `--protocol <ssh|https>` (default: `ssh`).
4. Supports `--install` to automatically build and install binaries to `~/.cargo/bin` upon clone completion.
5. Supports `--sync-mcp` to update Antigravity / Cline `mcp_config.json` after installation.
6. Integrates with `outfeed`'s progress reporting (`indicatif` spinners in interactive TTY, clean milestones in non-TTY).

---

## 2. CLI Interface & Flags

```bash
# Clone entire suite
outfeed clone --all

# Clone specific tools
outfeed clone miter storypole dado

# Clone entire suite pinned to exact suite.lock commits
outfeed clone --all --locked

# Clone via HTTPS instead of SSH
outfeed clone --all --protocol https

# Clone and immediately install binaries to PATH + sync Antigravity MCP
outfeed clone --all --install --sync-mcp

# Dry-run preview
outfeed clone --all --dry-run
```

## 3. Architecture & Module Design

### 3.1. `crates/outfeed-core/src/clone.rs` (<250 LOC)
* Types:
  - `CloneOpts`: `all: bool`, `locked: bool`, `protocol: GitProtocol`, `dry_run: bool`, `install: bool`, `sync_mcp: bool`.
  - `GitProtocol`: `Ssh`, `Https`.
  - `CloneSummary`: `repo: String`, `target_dir: PathBuf`, `status: CloneStatus` (Cloned, SkippedExisting, PinnedCommit).
* Functions:
  - `clone_repo(workspace_root: &Path, tool: &SuiteTool, opts: &CloneOpts, reporter: &dyn ProgressReporter) -> Result<CloneSummary, OutfeedError>`
  - `clone_suite(workspace_root: &Path, targets: &[&str], opts: &CloneOpts, reporter: &dyn ProgressReporter) -> Result<Vec<CloneSummary>, OutfeedError>`

### 3.2. `crates/outfeed-cli/src/args/clone.rs` (<120 LOC)
* Clap argument parser for `CloneArgs`.

### 3.3. `crates/outfeed-cli/src/commands/clone.rs` (<150 LOC)
* Command handler wiring `clone_suite`, spinner reporter, and optional post-clone install.
