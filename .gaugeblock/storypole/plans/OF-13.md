# GB-75: Implement outfeed sync to audit and align local checkouts with remotes or suite.lock

> **Status:** Ready  
> **Target Scope:** `outfeed-core`, `outfeed-cli`  
> **Key Invariants:**  
> 1. Hard 250 LOC rule on all `.rs` files.  
> 2. Zero-panic error handling with strongly typed errors via `thiserror`.  
> 3. Safe git execution: never overwrites uncommitted work or dirty working trees without explicit confirmation.  
> 4. Clean tabular and JSON reporting for human developers and Benchwork.  

---

## 1. Overview & Objectives

In a multi-repository workspace, developers and agents switch branches, make local changes, or need to align with newly landed releases. `outfeed sync` provides a unified multi-repo synchronization and alignment tool:

1. **Drift & Status Audit:** Inspects all 10 repositories, reporting current branch, dirty working tree status, unpushed commits, and distance from upstream `origin/main`.
2. **Upstream Synchronization (`--all`):** Fast-forward pulls latest upstream changes across all clean member repositories.
3. **Reproducible Alignment (`--locked`):** Checks out the exact commit SHAs pinned in `suite.lock`.
4. **Safety Invariants:** Refuses to pull or checkout if a repository has uncommitted changes (`git status --porcelain` check), reporting warnings clearly.

---

## 2. CLI Interface & Flags

```bash
# Audit status of all repositories without modifying anything
outfeed sync --status

# Pull latest upstream main across all clean repositories
outfeed sync --all

# Sync specific repositories
outfeed sync miter storypole

# Align all repositories to exact commits pinned in suite.lock
outfeed sync --all --locked

# Machine-readable output for Benchwork integration
outfeed sync --all --json
```

## 3. Architecture & Module Design

### 3.1. `crates/outfeed-core/src/sync.rs` (<250 LOC)
* Types:
  - `SyncOpts`: `all: bool`, `locked: bool`, `status_only: bool`, `dry_run: bool`.
  - `RepoSyncStatus`: `repo: String`, `branch: String`, `head_sha: String`, `dirty: bool`, `unpushed_count: usize`, `divergence: BranchDivergence`.
* Functions:
  - `audit_repo_sync(repo_dir: &Path) -> Result<RepoSyncStatus, OutfeedError>`
  - `sync_repo(repo_dir: &Path, opts: &SyncOpts, reporter: &dyn ProgressReporter) -> Result<RepoSyncStatus, OutfeedError>`
  - `sync_suite(workspace_root: &Path, targets: &[&str], opts: &SyncOpts, reporter: &dyn ProgressReporter) -> Result<Vec<RepoSyncStatus>, OutfeedError>`

### 3.2. `crates/outfeed-cli/src/args/sync.rs` (<100 LOC)
* Clap argument parser for `SyncArgs`.

### 3.3. `crates/outfeed-cli/src/commands/sync.rs` (<150 LOC)
* Handler rendering formatted status tables or JSON output.
